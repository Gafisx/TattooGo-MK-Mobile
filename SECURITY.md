Security Policy
Reporting a Vulnerability
Do not open public GitHub Issues for security vulnerabilities.

This includes, but is not limited to:

Authentication issues involving Clerk
Financial transaction handling
Express or Next.js API exposure
Unauthorized data access or leakage of personal information
Report security findings privately and directly to the Gafisx Labs security team. Do not disclose details publicly until the issue has been assessed and, if applicable, remediated.

We will acknowledge private reports and coordinate a responsible disclosure process.
